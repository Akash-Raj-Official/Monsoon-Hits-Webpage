# 🌧️ Monsoon Hits — Deluxe Lounge & Rain Beats Web Player

An aesthetic, viral web music player engineered with **Apple Liquid Glass / VisionOS Frosted Glassmorphism** aesthetics, dynamic responsive backgrounds, and full **YouTube IFrame Player API** integration for the official YouTube Music Monsoon Hits playlist.

## ✨ Features

- **🧊 Apple Liquid Glass Aesthetic**: Ultra-frosted glassmorphic playback pill, specular rim highlights, and localized mouse cursor spotlight gradients.
- **📱 Responsive Background Engine**: Automatically displays `Monsoon hits.png` for Desktop screens and switches to `Mobile.png` for mobile/tablet viewports.
- **🎵 YouTube IFrame API Synchronization**: Synchronized video playback, timeline seeking, and volume controls linked directly to YouTube Music video IDs across all 23 tracks.
- **🔊 Floating Volume Controller**: Non-clipping, unclipped glass popover floating above the miniplayer with smooth rise-up/fall-down animations.
- **⌨️ YouTube Music Keyboard Shortcuts**:
  - `N` / `Shift + N`: Next Track
  - `P` / `Shift + P`: Previous Track
  - `K` / `Space`: Play / Pause
  - `L` / `ArrowRight`: Seek Forward 5s
  - `J` / `ArrowLeft`: Seek Backward 5s
  - `ArrowUp` / `ArrowDown`: Volume Control
  - `M`: Mute / Unmute Toggle
- **🚀 Automated Deployment**: Built-in GitHub Actions workflow (`.github/workflows/deploy.yml`) for seamless deployment.
